## 2. Root cause (evidence-based, not guessed)

- `review_tool.py --set r` reads `datasets/pending_review/metadata.csv`; `--set n` reads `datasets/pending_transcripts/metadata.csv`. Both manifests were generated **only from `data/annotations.json` file_ids** (180 records) via `proposed_finetune_splits.csv`.
- `annotations.json` (generated by `scripts/parse_annotations.py` from `docs/kich_ban_thu_am.md`) covers only the A/B adult scripts → `Male 30`, `Female 30`, `Trẻ con/*`, `Giọng clone`, and the `Nữ 20 tuổi "(1)"` takes have **no annotation → no file_id → no manifest row → unreachable by the review tool**.
- The earlier STT benchmark (`evaluate_asr.py`) additionally filters to canonical folders, so those wavs never appeared in evaluation either. Nothing was missing from disk or conversion — only from manifests.
- The skew toward `Hoàng Tuấn/Nam 20 tuổi` in review output is because `--set r` iterates the 90 pending_review rows (speaker A = `A_*`+`Nam_C*` from that folder; `B_*`/`A_C*` from `Nữ 20 tuổi` appear later in the list).
